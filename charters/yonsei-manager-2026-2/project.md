# 프로젝트 지도 — YONSEI Manager

[계획서 2026-2](index.md) · [결과](results.md) · [운영 기록](ops.md)

YONSEI Manager는 LearnUS로 이루어지는 학교생활을 한곳에서 관리하려는 개인용 학사 비서다. 서버(집 데스크탑)가 수집·판정·알림·실행을 맡고, iPhone 앱이 화면과 승인을 맡는다.

계획서는 한 번에 **질문 하나**만 판정한다. 지금 질문은 "마감을 놓치지 않는가"이고, 다른 기능은 아래 표처럼 판정 대상이 아니다. **판정 없음은 "잘 된다"는 뜻이 아니라 "아직 기준이 없다"는 뜻이다.** 기준이 필요해지면 그 기능만의 계획서를 따로 쓴다.

운영 상태는 2026-11-05 기준이다.

| 기능 | 하는 일 | 운영 상태 | 판정 |
|---|---|---|---|
| LearnUS 수집 | 과목 8개의 과제·Turnitin·퀴즈·시험·공지·출석 VOD와 마감을 읽는다(읽기 전용) | 운영 중 | **2026-2 계획서** |
| 표시·알림 | 앱의 오늘·할 일·인박스, 마감 전 알림 | 운영 중 | **2026-2 계획서** (앱 표시·반영 지연까지) |
| 출석 자동 재생 | 승인한 VOD 재생, 승인이 없으면 마감 직전 자동 재생 | 운영 중 | **2026-2 계획서** (승인 규칙 §2, 승인 없는 행동은 S1) |
| 퀴즈·과제 제출 | 검토본을 승인받은 뒤에만 LearnUS에 제출 | 코드 있음, 퀴즈 자동 제출은 꺼짐 | 판정 없음. 단 승인 없이 LearnUS에서 행동하면 2026-2 계획서의 S1 |
| 자료 동기화 | 강의 자료를 로컬·Google Drive에 받아 정리 | 운영 중 | 판정 없음 |
| 강의 전사 | 강의 영상을 데스크탑 GPU로 받아쓰기 | 꺼짐 (2026-10-25 장애, 원인 확인 전) | 판정 없음 |
| 공지·자료 검색과 공부 노트 | 본문 검색, 요약, 자동 공부 노트 | 운영 중 | 판정 없음 |
| 공부 계획 | 공부 블록 배치, 세션 기록 | 기록이 거의 없음 | 판정 없음 (지금은 측정 불가) |
| 과제 초안 작성 | 과제 요구사항을 읽고 초안·문서 생성 | 운영 중 | 판정 없음 |
| 앱 에이전트 | 앱에서 Claude·Codex에게 묻고 맡기기 | 운영 중 | 판정 없음 |
| 비용 계측 | LLM 호출의 토큰·소요 기록 | 기록률 약 2% | 판정 없음. 2026-2 계획서 §6은 기록률만 요구 |
